Конструктор инапов

Соберите шаблон, скопируйте код и вставьте его в конструктор Mindbox — разметку в поле HTML, стили в поле CSS.

Показ и оформление
Тексты
Оставьте пустым, чтобы убрать блок.
Пусто — кнопки не будет.
Промокод
Копирование сделано на JS: атрибут SDK закрывает инап при нажатии, и человек теряет инструкцию из виду.
Откуда берётся лот
{id} заменится на id лота.
Куда вести, если лот не подгрузился. Карточка при этом скроется.
Источник товаров
Списки склеиваются, дубли убираются по id лота.
Действие кнопки
Вопросы
На остальных вопросах кнопка берёт текст из поля «Кнопка действия». Нужна только вопросам с несколькими вариантами — остальные переходят дальше по нажатию на ответ.
Вопросы идут по очереди, над каждым — «Вопрос 1 из N». Ответ на каждый вопрос записывается в Mindbox сразу, поэтому ответы сохранятся, даже если человек закроет опрос на середине.
Куда записывать ответы
Одна операция на весь опрос. Поле клиента задаётся у каждого вопроса. Операция и все поля должны уже существовать в проекте и операция должна уметь их записывать.
Экран благодарности
Пусто — без текста.
Фильтр по брендам
Через запятую. Пусто — показываются любые бренды. Регистр, пробелы и дефисы не важны.
Подключение
У Android своя точка входа.
